# M04.8 香炉迁移：实际边界与保留失败

原版香炉的独立美术、30 秒真实计时、跨刷新恢复、燃香 +2 结算、烟雾、火苗及桌面阴影已经迁入动态 Home。框架只负责通用校验存档和公共气泡；游戏保存 schema、倒计时、烟雾和交互规则；构建仓只提供导入、候选和证据工具。

`M04-incense-v4-tests.log` 的 67 项检查全部通过，`M04-incense-v2-typecheck.log` 的类型检查退出 0。Creator 3.8.8 最终运行候选和固定时刻候选退出 36，并有 completed 日志及真实非空浏览器画面。浏览器最终运行候选 URL `127.0.0.1:8820` 的警告、错误为空；此结论不覆盖其他候选及原始 Creator 进程调试日志。

实际点击证明：点击后的 .28 秒回弹尚未结束时 Escape 可取消；再次点击才点燃，燃烧中的重复点击不增加 burnCount、不重置时间；显示“还没燃尽”公共气泡；刷新恢复剩余 13.095999956 秒；燃尽只结束一次，奖励恢复 +1。长按外部空白位置期间气泡保持 hold，并消耗这次输入。动作、截图和时间字段见 `builds/records/M04-incense-flow.json`。

固定时刻对照明确修改了 QA 源码：两引擎均固定真实时钟，隔离存档，程序点燃并以 60 个 1/30 秒步进到 2 秒；主角与植物保持休止姿势，房间固定正午。它不是物理点击、真实持久化、原封不动发布包或微信设备证据。两引擎均剩余 27.9999999999999 秒、61 个烟雾点。所有点的日志坐标最大分量差 0.0001260195，含 Godot Vector2 字符串舍入。截图没有对齐、缩放、调色，差图没有放大颜色；烟雾/香身区域平均 RGB 差 1.17950、陶瓷/桌面影区域 1.41744（0–255）。这些残差不是一比一验收通过。

## 保留失败

- 首次计时测试错误地要求：墙上时钟跳过截止时刻，而单调时钟只过去 .02 秒，也应耗尽所有余烟。原 Godot `_advance_clock` 在此只把剩余归零，并从观察到的燃尽时刻保留 5.6 秒余烟。修正测试假设，另测单调时钟完整过去 37 秒后余烟归零。失败日志 `M04-incense-v1-tests.log` 保留，产品算法未为错误测试而改动。
- 运行 v1 记录了旧 LabelOutline/LabelShadow 属性的四种弃用警告。改用本机官方 Creator 3.8.8 Label 的 outline/shadow 属性，运行 v2 URL 范围内警告和错误为空。旧构建日志和截图保留。
- 固定时刻 v1 的隔离测试适配器忽略全部写入，触发正确的 `checkpoint_write_failed:verify_temporary_save_failed`。v2 改用隔离 Map 进行真实 readback；没有绕过生产校验。v1 候选及截图仍保留，其持久化失败属于候选适配器，不能作为产品存档通过证据。
- 早期文件名含 `ignited` 的 v1 截图实际捕获回弹尚未结束、尚未点燃；含 `busy-tip` 或 `tip-runtime` 的早期截图在气泡自动消失后才捕获，未显示气泡。这些保留为失败捕获尝试，不能用于可见点燃/气泡证明；真实可见气泡使用 `cocos-incense-tip-held-runtime-v2.jpg`，点燃使用时间日志及固定时刻截图。
- 初次完整性检查错误地要求旧运行 v1 与最新源一致，触发 `Production differs: engines/travel-core/dist/travel-core.js`。最终记录明确列出旧实现差异，以及冻结后补充的测试文件；所有候选运行源仍与各自冻结清单一致，仅 58 个 Creator `.meta` 修改 `files/ver/imported` 字段。最终运行 v2、固定时刻 v2 与当前运行源一致。
- 首次来源清单尝试读取原始 `incense_ceramic.png`，但原仓库只有对应 `.import` 和发布缓存，触发 FileNotFoundError，未生成错误记录。最终清单记录实际存在的 `.import` SHA，像素来源沿用已验证的 M02 原缓存解码与裁切记录，未伪造不存在的原 PNG 哈希。

框架软链接指向模式 0444 的发行文件，目录 0555，SHA 与候选匹配。用户工程 16 个基线文件中 15 个仍原字节，只有此前已声明的 Boot 接入变更；场景和脚本 UUID、720×1280 保持不变。完整记录见 `M04-incense-source-integrity.json`。
