# 赵云与阿斗 · Cocos 复刻工程

在用户新建的空项目上开发，使用 Cocos Creator **3.8.8**。打开本目录，运行 `assets/scene.scene`；Boot 会动态创建界面，无需重新挂组件。原项目、场景和 Boot UUID 均保留，设计尺寸仍为 720×1280。

点击征兵，拖动字牌到己方空地；同类同级合成升级，铲子开垦。武将名字按正确顺序左右相邻后组合。武器背包中，点击武器查看说明，**拖动武器到武将卡片上装备**。支持鼠标和触摸，离开前自动保存，后台暂停。

已接入四张原始地图、原版界面与字形、骨骼曲线及网格权重、2 个主动和 6 个被动道具槽、商店与抽奖、满栏替换、12 种 Boss 技能、武器触发效果、碎片累计合成、体力、军衔、存档和一次性结算。对手由本地 AI 控制；原游戏的联网匹配、排行榜和广告服务尚未接入。

## 构建

在工作区 `little-steps-cocos` 根目录执行公共入口：

```sh
python3 -B builds/build.py wechatgame --game zhaoyunyuadou
```

本游戏固定输出为 `builds/wechatgame/zhaoyunyuadou`，采用微信原生分包。配置中的 `touristappid` 用于本地开发候选，不是发布 AppID。浏览器截图候选及本地 HTTP 服务只用于验证，不作为真机资源服务器。
