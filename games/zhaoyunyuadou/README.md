在用户新建的空项目上开发，使用 Cocos Creator **3.8.8**。打开本目录，运行 `assets/scene.scene`；Boot 会动态创建界面，无需重新挂组件。原项目、场景和 Boot UUID 均保留，设计尺寸仍为 720×1280。

点击征兵，拖动字牌到己方空地；同类同级士兵、农民合成升级，铲子开垦。独立同字牌交换位置；把相应字牌拖到武将任意一半上可以喂经验。武将名字按正确顺序左右相邻后组合。武器背包中，点击武器查看说明，**拖动武器到武将卡片上装备**。支持鼠标和触摸，离开前自动保存，后台暂停。
