- 参考视频：`/Users/wkk/Downloads/bc765723e70bda6ecc8189203cd990e6.mp4`，约 201 秒，432×960，游戏画面需逆时针旋转 90° 后观察。
- 复刻范围：启动与目录、内容详情、卡牌进入、发牌、出牌、抽牌、回撤、万能牌、补牌、暂停与返回、连击奖励、完成与过渡；按钮、UI、特效、出场按参考逐项对照。
- 竖屏布局须保留上述元素与操作；横屏与竖屏无法以整屏像素坐标直接相等判定，应同时比较元素外观、相对布局和对应动作帧。
- 视频内所有剧情（包括约 57–67 秒的介绍与 155 秒后的剧情）不复刻。保留本工程 `assets/mods/base-avg`、`assets/art/dramas` 及现有剧情 JSON；衔接通过既有 AVG 入口，不能换成视频剧情或删减现有配置能力。
- 卡牌牌型/关卡继续从 `config/card-levels` 动态读取 JSON，保留 schema、牌位、遮挡、坐标、旋转和资源校验；不能改成硬编码关卡。
- 安卓渠道通过 `python3 -B builds/build.py android --game avg_plus` 构建最新已保存代码，隔离构建并检测构建中输入变化；原生竖屏，产物与打包配置独立于微信渠道。
- GitHub 热更新覆盖游戏脚本、配置和素材；具备内容校验、失败重试、断网本地启动、启动前搜索路径恢复、重启生效与原生兼容限制。安卓 native/引擎变化须重新安装 APK。
- 最终需有可安装安卓包、安卓实测日志和截图、逐按钮操作/动画证据、GitHub 发布下载及旧包升级到新资源的实际验证。网页或单元测试通过不能替代安卓验收。
