# 照片墙生产分层美术候选

本轮只交付材质资产，不代表照片墙动态、交互、共享昼夜、官方导入或游戏渲染已验收。以 `approved_design_handoff.txt` 的单页规则为准；完整静态设计图只保存在本目录，不进入运行包。

## 运行资产

路径前缀：`games/travel_woodfish/project/photo/assets/`。

- `photo_wall_neutral_plate_v1.png`：941×1672，原生成 PNG 字节一致复制。保留藤叶白花、暖墙、下方木地板和左下空草垫。清除照片、照片绳、夹子、字牌、文字、角色和纸摞；无窗、无强定向阳光光束。720×1280 构图下草垫中心约 (214,943)，地板起点约 y=891，动态鱼中心可从 (205,880) 起调。
- `photo_wall_material_atlas_v1.png`：768×544，真正 RGBA 透明图集，不带底色。纸框 Rect2(16,16,416,512)，独立选择木夹 Rect2(464,16,288,216)。纸框内部照片 underlay 建议为纸框局部 Rect2(39,42,340,386)，底边印记区为 Rect2(64,438,288,52)。这些是绘制覆盖参考，仍应按实际纸面 shader 校准。

纸框显示到 208×256 逻辑像素、木夹显示到 144×108 时具备 DPR2 采样。底板在约 470×836 逻辑视口具备 DPR2；720×1280 的设计画布只达到约 1.307 纹理像素/逻辑像素，未通过放大图片伪称完整 DPR2。

## 源图和制作

全部绘画内容由内置 `image_gen.imagegen` 参考编辑生成，原始提示在 `generation_prompts.json`。生成原图原样保存在 `sources/`；两份认可设计参考图和交接文字与原文件一致保存。不是旧原画逐像素提取，不声称新的生成笔触已获用户单独验收。

经父任务明确允许，`prepare_assets.py` 仅做确定性裁边、LANCZOS 缩小、透明图集像素复制，不重绘、不加投影、不生成文字、不叠加伪动态。复现：

`python design/photo_wall/prepare_assets.py`

Pillow 版本、每张源图与运行图 SHA256/RGBA8 hash、裁框、图集坐标、查看记录均在 `provenance.json`。最终装配图已实际查看，透明孔洞和图集空区 alpha=0。生成木夹局部 alpha 接近253属原生成透明度，未强制改成255，也未加底色。

## 资源预算与待验证边界

仅两张运行 PNG，合计 2,434,992 bytes；RGBA8 基础解码合计 7,964,576 bytes；每图加 64KiB 准入开销后 8,095,648 bytes。不要求 mipmap，不增加额外运行图或源设计图。

集成方仍须：分配真实延迟照片包、确保 Home 首包不依赖照片素材、用固定官方 Godot 4.5.2 lossless 导入并逐 RGBA8 hash 核验、实际检查昼夜与移动光照、照片纸面形变/投影、夹子和角色统一受光。未进行 push 或部署。
