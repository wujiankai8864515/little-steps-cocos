# 守护我的发际线

Cocos Creator **3.8.8** 微信小游戏。产品需求来自 `docs/requirements.md`，视觉基准来自 `source/references` 中用户提供的两张产品示意图。工程入口为 `assets/scene.scene`，Boot 已挂载，无需手工拖组件。

## 运行与构建

用 Cocos Creator 3.8.8 打开本目录。在仓库根目录构建微信原生分包：

```sh
python3 -B builds/build.py wechatgame --game hairline
```

微信开发者工具打开 `builds/wechatgame/hairline`。当前配置采用用户于 2026-10-22 指定的 AppID **`wx4d41972686e54c11`**，渠道配置在 `builds/wechatgame/games/hairline.json`。本地构建与《赵云与阿斗》保留独立目录；本次只切换本地工程 AppID，不上传或覆盖体验版。产物不依赖资源服务器，不需要同 Wi-Fi，不关闭域名与证书校验。

## 已实现的玩法

- 初始三根毛、60 窝囊费、六格鱼塘。召唤一次填满五格营地，初始费用 10，之后每次 +2。第一组提供怼、摆、摸、拖和铲子作为引导，后续按概率随机召唤。
- 拖动营地单位到鱼塘；同名同级合成至五阶；不同单位可换位；场上单位可拖回空营地；咖啡模式移除单位；铲子只开拓相邻、非道路的空格。
- 四种基础单位分别具有单体高伤、穿刺减速、远程泡泡、近战群伤击退；攻击与攻速采用策划中的五阶系数。摸每 18 次命中恢复一根毛，上限三根，用于避免无限满血。
- 病、假、工、伤、外、出、中、奖单字零输出。两字拖在一起，激活永久的病假、工伤、外出、中奖；16/20/30 次攻击技能分别执行眩晕、索赔击退、全场伤害；外出持续贯穿群伤。
- 每六波出现老板；降本增效、全员大会、末位淘汰依次轮换。掉毛、血条、命中摇晃、攻击效果、合成提示、Boss 驳回提示和音效均由实际战斗事件触发。
- 三档 AI 拥有自己的钱、鱼塘、营地、单位、敌人、随机数与头发；同一波次和 Boss 规则对双方生效，AI 不改变玩家的召唤结果或资源。
- 暂停、返回首页、未完成对局恢复、一次性结算、签到、成就、当日体验卡、音效/音乐、震动开关、老板本地换头像。

## 微信平台接入边界

`assets/game/Platform.ts` 封装激励视频与选图。配置真实 `rewardedAdUnitId` 后，完整观看才发放扩张、护盾、资源或一次续命奖励。提前关闭、失败、重复回调均不重复发奖。未配置广告位时隐藏奖励入口，不使用假视频或直接赠送来冒充广告接入。没有内购、充值和付费商城。

老板头像仅在玩家主动选择图片后读取，保存到本游戏本地存储；没有头像上传服务器。微信真机广告、相册授权、性能与商店发布须在生产 AppID 和实际设备上另行验证。

接口依据：[微信小游戏激励视频接口](https://developers.weixin.qq.com/minigame/dev/api/ad/wx.createRewardedVideoAd.html)、[微信小游戏选图接口](https://developers.weixin.qq.com/minigame/dev/api/media/image/wx.chooseImage.html)。

## 结构与素材

`assets/game/Model.ts` 为不依赖引擎的战斗、AI、经济、存档与奖励规则；`HairlineGame.ts` 管理页面和交互；`OfficeUI.ts` 封装 Cocos 节点、画笔与字体；`Platform.ts` 管理微信接口。框架通过只读软链接消费，资源准入保持 80 specs / 128 entries / 256 MiB。

办公室主视觉、地砖、水面、道具侧边和狗腿子来自用户提供的图片裁切。主视觉保留原始参考，游戏版本缩放至 720 宽并采用 256 色 PNG，单张小于 500 KB。字体为现有工作区的文楷、马善政子集，OFL 许可证在 `source`；背景音乐和短音效为原创合成单声道 PCM。哈希及来源见 `source/asset-manifest.json`。未将整张带单位的战斗示意图当成可玩画面。
