# M04.13 背包真实输入、询问与归墙

本项接入真实浏览器指针的背包入口，仍是部分迁移。原版源码 `b4f77afc02999a465757177794343eb3d531c5e6` 未修改。Cocos 本项基于 `2e13fa65a5a0d0af4add238f28ef6aebeebc25fc`；生产文件与原版脚本 SHA 见 `../records/M04-bag-input-flow.json`。

## 实现及证据

- 复用真实透明像素和当前变形三角形命中。轻点只产生原反馈，移动超过 9px 或长按 .34s 提起；另一指针不能抢占。实际浏览器轻点、420ms 长按、无效落点、递交主角、取消按钮和气泡外取消均保留公开控制器日志。
- 使用背包实际绘制顶点限制 18px 安全边距，落定 .36s。递交后才暂停主角并调用原 .24s 穿戴骨骼；取消恢复骨骼并 .24s 回墙。既有五块挂墙网格、五块穿戴网格和十块墙面投影的 20 个节点移到临时前景层，结束后恢复；没有替代演员或复制背包。
- 框架只新增通用确认布局、选项和指针所有权；游戏提供文案与路由。通用气泡保留原 62px 选项行、44px 按钮、12px 间隙、分隔线、取消文字浅色、头部净空、弹出/渐显/关闭阶段。滑出按钮永久取消本次选择，气泡外按下穿过纸面后返回也不触发。询问优先于设置入口和房间输入。
- 原版询问 `automatic_input=false`，Escape 被忽略。v4 实测两边仍显示询问和穿戴；随后点击「再等等」均回墙。Cocos 保留原非路由模式的准备信息作为尚未接入旅行时的边界，不能把它当作旅行实现。
- 原版与 Cocos 最终穿戴代理位置均 `[94,719]`，握锤 `.5`、肩部 `[113,-15.5]`、尾部比例 `[1,1.5]`。纸面 `[190,504.5,320,142]`，两按钮 `[208,592.5,136,44]` / `[356,592.5,136,44]`；Cocos y 差约 `7.4e-7`。五个日间落地投影、floor951、重建一次；携带日志显示前景层20节点且穿戴落地投影0。
- 96 项测试通过，生产与最终候选类型通过。四份官方 Creator 构建均 exit36，并有 Finished 日志和实际非空浏览器画面；不是正式微信包。冻结候选 527 文件均无运行文件变更，编辑器只调整一份插件元数据的 ver/files；原场景、Boot 挂载/UUID及15份用户基线文件保持。

## 差异与失败保留

1. v1 少确认分隔线，且 Cocos 使用实时自主敲击、原版使用静止对照，功德状态不同。保留 `bag-offer-noon-*-v1.jpg`、原始公开日志和构建。按原框架源码补线，并在显式 QA 覆层中统一静止状态；生产自主动作保留。
2. v2/v3 原取消文字需要 `ink.lightened(.13)`，已按源码补齐。v2 的按钮滑出仍保持询问，截图保留。
3. v3 的 Escape 误取消询问。原版实测仍穿戴，源码确认通用键盘取消以 automatic_input 为条件、HomeNote 禁用该条件。保留 `bag-escape-mismatch-*-v3.jpg` 和 `M04-bag-input-browser-v3.json`；v4 修正为询问及背包指针状态忽略 Escape，实际回归保留在 v4 日志与截图。
4. 最终实图并不逐像素一致：原强度 RGB 差异的询问区域均值约4.8202、穿戴背包约5.3001；原版花束已增长，候选花束较少，日光/投影、字体栅格及纹理采样差异仍可见。回墙背包区域均值约.6146。没有挪齐、缩放、调色或放大差异后冒充通过。
