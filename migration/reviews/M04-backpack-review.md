# M04.11 挂墙背包：原版网格与实际浏览器检查点

按最新 Godot `articulated_backpack.gd` / `spring_mesh_part.gd` 迁移五个部件、十五节骨骼与两条原测量背带。Cocos 运行时提交 339 顶点，保留 UV、三角形索引、曲率限宽、面翻转稳定器、每帧至多四个 1/120 秒子步。复用原图和 alpha 位图，未引入 Spine。隐藏原整张背包代理绘制，保留其变换节点；新部件接入原光照接收器和十个移动 alpha 阴影通道。

两层节点分别承接代理和部件变换，保留非等比缩放后旋转产生的实际仿射效果。命中方法将绘制三角形反映射至原 UV，再查询离线 BitMap。当前只完成挂墙呈现，完整道具输入尚未接入。

## 实测范围

- 中午、静止：Godot `godot-backpack-noon-v2` 与 Cocos `cocos-backpack-noon-v1` 的真实 405×720 截图。全部索引与骨骼角度一致；顶点最大差 0.000091552734375 原图像素。当时存在五个 UV 分量的向量 float32 转换顺序差，后续源码已修正。
- 夜间 00:30、摆动 1.2 秒：Godot `godot-backpack-night-motion-v1` 与 Cocos `cocos-backpack-night-motion-v2`。实际公开日志逐项比较 678 个 UV 分量、1260 个索引分量、15 个角度及15个速度：全部完全一致。顶点最大差 0.0001220703125 原图像素；两边零翻转三角形。当前 URL 无错误，Cocos 实际 Canvas 为 405×720。
- 原始截图不对齐、不缩放、不改色；差分不放大。背包区域平均绝对 RGB 差为中午 0.6146/255、夜间 1.8089/255。夜间最大通道差32，仍需校准灯光、半透明边缘与 GPU 采样；不能据此声明逐像素完全相同。
- 原 Godot 公开运行状态还返回最新版穿戴五层网格的数量，仅作后续迁移参考，当前未作为穿戴渲染验收。

## 修复及保留的失败

- 首个 Godot 夹具使用了其他函数内的局部 `props` 变量，产生 parse error；改为显式查找节点并创建新 v2 夹具，原包与失败记录保留。
- 首次本机 HTTP 启动被沙箱拒绝，目录参数也与 build-config 的输出不一致；使用已授权的 loopback 服务和正确输出路径，另存 v2 日志。
- 首个摆动 Cocos 夹具在取得实际代理位置前推进，造成假惯性。v2 在真实位置复位后推进相同72帧；所有关节值精确匹配。保留 v1 状态和差分图。
- 同时修正生产几何换装/自由拖拽时的采样位置保留，避免重置为原点产生假速度；加入回归检查。
- 新审计工具最初误要求 Native 插件标志；目标只有微信小游戏，实际 Native 关闭是正确配置。工具改查 Web/MiniGame/global、Editor/Native 关闭，未修改插件产物。
