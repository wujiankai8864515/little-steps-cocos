# Home first-screen loading fix

Confirmed incident: the user's v23 HOME_PACK_FAILED diagnostics contain two host `Pack download timed out` errors for travel.pck. Core, entry, comic and exterior were mounted; the resource loader had no failures. This is a transfer-stage failure, not a WebGL initialization failure. The cloud browser fetched the exact authenticated hash-query URL successfully, which does not establish the user's network/cache behavior.

History: Home's travel dependency already existed in the recovery baseline. Travel grew from 8,282,068 bytes (v21) to 22,912,472 (v22). Eight v5 lossless textures added 14,597,236 bytes (99.77% of the growth); the subset font added only 22,733. v23's travel pack is byte-identical to v22. Thus the existing first-screen dependency became much more expensive; the v23 deadline correction did not reduce that payload.

Repair: Home no longer depends on the travel pack. Home owns the small font, state content, props, rewards, light, and exact approved tent/backpack pixel crops necessary for new, away, and returned saves. Full map/event/diary textures are loaded only after an explicit page request. A native cancellable progress panel keeps failed or interrupted travel downloads from blocking Home. Closing or suspending it prevents stale completion from reopening a page. Home rewards remain usable without the page pack. Existing deadline/cancellation diagnostics are retained; this change does not extend network timeouts.

The source mother image remains in editable source; the runtime includes only the exact required crop pixels. UVs shift by the crop origin, while polygon geometry, world placement, artwork and colors stay unchanged. The build asserts pixel identity, Home's lack of travel dependency, a 19,000,000-byte deferred Home ceiling, and each shipped font below 1 MB. Recovered import sidecars and their runtime textures follow the current logical ownership rather than stale baseline pack assignments.

The build now runs the exact dynamic PCK loading test with the travel pack initially absent, persisted away/returned state, slow/cancel/failure/retry/warm routes, and the six bounded deadline tests. Headless tests do not certify browser GPU, audio, network behavior or touch feel. The full production App journey is checked separately. No travel UI redesign is included in this loading-only release.
