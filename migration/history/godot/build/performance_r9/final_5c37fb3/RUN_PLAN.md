# 同机前后计时计划

从替换后的同一云Linux机器，使用同一官方Godot4.5.2、同一外部profile.gd、720×1280、X11 Mesa软件GL、Dummy音频、maxFPS60。每场景独立进程、空res根、独立HOME/XDG；OS磁盘缓存不受控制。R8使用恢复的原始官方Web PCK并注入本地包后端；R9使用正式5c37fb3 native PCK，同一控制器入口。

启动、暗室、照片、衣柜、旅行、收藏、日记、出发八个场景，每个适用页首次与两次暖进入。进入计时包含原过渡动画，Comic通过正式完成回调结束，故事停留不计。不是浏览器网络/手机/硬件GPU结果。游戏时钟自然运行，细小draw差异和尾部分布不能直接归因于优化。Performance.TIME_PROCESS是采样监视值，不能当每帧CPU耗时；实际进程帧间隔单独记录。

两个版本按场景配对顺序运行，避免把整个R8与整个R9相隔很久。只有单一GL进程运行。正式GUI功能测试和headless重循环先结束，避免争用。R8已知多边形错误保留为基线缺陷；R9同错误为失败。
