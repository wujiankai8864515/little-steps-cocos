本版的最新七项修正已在正式同源包完成实际输入、画面和生命周期检查。照片和旅行暖进入有明确改善，收藏与日记首次进入减少等待；衣柜和旅行冷进入受软件GL波动影响，未宣称稳定提速。Comic首次绘制仍是明显瓶颈，整体内存没有测得下降。

## 内存与音频

同一外部夹具，1次预热后20轮跨衣柜、收藏、照片、旅行、日记和暗室。两个版本均保持107个资源门禁条目、241,557,892字节准入估计；新版本缓存资源236，R8为233。缓存资源数只是一种计数，不等于全部临时对象。

原生RSS在20轮中保持平台：新版本406,163,456字节，R8为405,659,648字节。新版本未测得总体RSS下降；不得把更少重复分配直接说成整体省内存。

初次严格恒定断言发现+13节点和逐轮对象增长，原红记录保留。节点已按路径/类确认是正常自动长出的Flower_1；对象则是实际自主敲击令“功德 N”更新，字体测字生成TextLine。

在不清缓存、不改时钟/收益/资源的75次衣柜诊断中，默认字体LRU第51轮达到平台；52至75轮功德继续变化，对象3993（一次3992瞬时差）。RSS第49轮增加4,096字节，从406,188,032变为406,192,128后平台。测量结束后的独立归因操作证实bootstrap_ui.ttf单行缓存恰好64项，与官方默认64单行/16多行一致。这是正常有界驻留，不计为一次新修复，也不以清理后的数字宣称节省。

两个版本拆除后只剩1个根Window，0 orphan节点；未发现该路径上的无界切页增长。这不是任意时长、任意玩法或浏览器完整内存审计。

正式包正常headless关闭7场景共91检查，0对象泄漏警告；播放已启动场景实际退休等待60至113毫秒，未播放场景1毫秒。

真实X11窗口关闭另22检查通过：2个播放对象实际退休，91毫秒，0剩余引用和0ObjectDB警告。

另16项诊断明确保留：故意持引用的1秒超时，以及直接SceneTree.quit留下2个MP3流和2个播放对象警告。浏览器AudioContext/createBuffer未由原生关闭结果证明解决。

## 剩余边界

- 所有性能计时必须区分云原生软件GL与实际浏览器、手机硬件。此云浏览器能加载HTML、初始化引擎和校验PCK，但不能建立WebGL2游戏画面。
- 原生资源准入估计、Godot对象计数、Linux RSS分别报告。池容量稳定不是总内存更少；PCK已挂载后无法卸载。
- Comic与后台Home首次着色绘制仍慢；本次软件GL同机首显约15.6至15.9秒，未证实改善。单次同步大纹理load仍不可拆帧。后续冷Shader共享仅在独立候选中调查，未纳入本版收益。
- 宿主关闭能阻止迟到结果启动或揭幕，但官方公开preload接口无法中止已经发出的core下载。
- 用户新授权W2/W5/W6/W7属于视觉或交互修正，不与保持原画的性能优化混为一类；最终审美、手机触感、Web听音与真实浏览器存档仍需用户设备验证。
- 云工作区曾被替换。R9源从已核验私有GitHub恢复，原临时QA原始文件丢失后重新测试。旧口头通过数不代替此次正式证据。最新源和每个完成批次已增量存入Library并固定读回。
