来源：Sentinel_cb2fc9a24ff481919d6ec510026d5ef1。源码/新美术组件候选，不把用户否定的旧画面等价验证当认可。

先查看实际96×128旧图及绘制逻辑：旧图为狭长深褐写实脚印；_draw_footprints 每个已到站节点循环绘两只17×29脚印。内建image_gen依据已查看旧图进行原创参考改绘：柔圆脚掌、五个圆趾、暖赭水彩、真实透明alpha。改为每站仅绘一个26×35足印。到站drop/press/settle、既有站点不重播、未来站点不预铺的逻辑不改。

设计原稿、完整prompt、旧图对照、可复现透明缩样脚本及来源/hash保存在design/travel_footprint_cute。为了不同时驻留两套图，显式替换原runtime身份travel_footprint_ink_v1.png；旧design/travel_footprint_ink是历史原稿/旧输出哈希，已被本项覆盖，不能当当前生产图。原runtime import sidecar无需改变。

资源仍是travel_visual→travel.pck的同一个资源项：96×128 RGBA8，49152解码bytes，无mip，声明估计114688bytes，与原图相同。新版PNG17040bytes。运行显示26×35，原图尺寸覆盖静态DPR3；入口最大1.35倍在DPR3可能轻微放大，已列明而非声称无限高清。
