# A083 拖起漫画反馈遮挡：查后修复（候选）

## 确证红与根因

正式 d817 包、空 res 根、真实 App 根输入长按三次；画面冻结仅用于同帧严格像素对照。三个抓点关闭/开启符号均为 0 像素差；隐藏鱼后分别 217、222、217 像素。鱼已被提升到 CanvasLayer 40，反馈仍在 HomeWorld 的 z84，所以完全被身体挡住。不同 CanvasLayer 之间单改 z 不能解决。

诊断 v1/v2 的“升层”控制无效，因为 reparent 会触发反馈节点 _exit_tree 并 clear。v3 明确保存及恢复诊断状态后，三个同姿态升层控制各恢复 224 可见像素。这些控制仅在外置 QA 中，不属于生产修改。

## 生产最小修复

只改 home_page.gd：在鱼长按进入拖拽且新反馈尚未发出前，把原 ActionMarks 一并纳入现有最高拖拽 CanvasLayer，z181 高于鱼 z180。记录原 z，松手/取消时重回原父节点和 z84。保留 _exit_tree 清理过期反馈，未创建复制鱼/输入遮罩，未修改素材、颜色、尺寸、持续时间、脸部避让或资源下载。
