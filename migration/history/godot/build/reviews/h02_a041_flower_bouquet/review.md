# H02 / A041：花束高低、曲度和旧档几何迁移

基线：56193b766b3c13d83ac5aee7149f4d8045e5733e。生产变更仅限 home/flowers/flower_life.gd 和 flower_stem.gd。本项不改 HomeWorld、敲击、props、共享时钟、发布或用户存档路径。

## 确证原因与修复

用户截图中的多花同高同向问题在原生真实 Home 复现：旧十朵正午端点仅分布在 x=-29…28、y=-68…-105 的局部区域，部分花头相隔不足 7 像素。旧基础曲度只保留 55%，统一太阳弯曲可达 0.86，早晚进一步收成近似平行茎；旧 schema3 又直接保留花的几何记录，只改新花生成函数不能让已有存档改善。

- 用十个按 ID 固定的低、中、高布局槽交错高度、基础曲度和瓶口根位，并仅在记录建立/迁移时计算微小确定性差异。位置不依赖当前花数，不在每帧随机，也不会因为新增花而重排旧花。
- 保留基础曲度的完整幅度，太阳附加弯曲减为 gain=0.31、上限0.50。茎有按已存 phase 确定的下上段反曲，花盘仍用既有局部/世界坐标转换独立指向虚拟太阳。
- 保持几何外的 schema3 规则，增加 geometry_version=2。旧 schema1/2/3 的记录通过原范围校验后，仅规范 height/bend/root_x/head_size；ID、出生时间、生命周期、active_seconds、next_birth_seconds、next_id、revision 不在几何迁移中改变。旧存档首次读取即能显示错落，后续正常保存记下新几何版本；重复恢复不再次调整。
- 所有茎、轮廓和叶子放在全部花盘之后；固定花瓶前沿继续覆盖根部。这样较晚 ID 的长茎不会横穿较早 ID 的花盘。
- 右下花适当抬高并保留间距，避免极傍晚/夜间靠近“点击燃香”文案。

没有新图、贴图或字体；所有原美术、虚拟太阳以花瓶中心作上半圆180°轨迹、昼夜转换和ZZ逻辑保持原调用。

## 真实验证与证据

官方 Godot 4.5.2 Linux，原生 Xorg + Mesa llvmpipe OpenGL Compatibility。工程由固定561源码的独立文本副本和同版官方导入资源组装；没有运行 PATH 中的4.6，也没有改冻结快照。

终版结果和真实渲染联图见同目录，逐张原始整屏PNG路径与SHA256见evidence_manifest.json。3、5、10朵均从旧 schema3 fixture 写入隔离 user:// 后，由真实 Home configure → Store.load_into → Life.restore 路径载入，拍早、午、晚；另拍十朵3秒半闭/9秒全闭后的ZZ夜图及390×844、430×932完整手机尺寸；新档从1朵按原规则长到10朵，也重拍早午晚和夜图。基线截图来自同机同引擎实际运行；联图仅把固定屏幕区域的原像素放大2倍，未重画；单张_detail另为3倍查看用。

fixtures/flower_geometry_v1 中 existing_schema3_1.json 是固定561隔离运行保存的实际一朵旧档；3/5/10朵由固定561实际运行增长后保存。专项检查新建与旧档相同ID得到相同几何、保存/重载稳定、几何迁移幂等、原始边界不奖励额外花，并检查59.999/60秒出生、4/8秒渐长、10朵停止。

最终467项专项与305项旧回归通过。最小花头中心间距30.432局部像素，旧十朵早/午/晚高度跨度110.79/94.62/81.44局部像素；完整扫动最大端点步长0.2185像素、最差追光点积0.99482。完整日弧整束离屏幕最近的水平边界仍有4.69像素；详细读数见 results.json。完整30秒、901帧、十朵太阳扫描检验固定根、每段仍向上、端点连续运动、花盘追光方向。旧 test_round5_eyes_flowers.gd 另跑305项，覆盖旧schema1/2迁移、存储、生命周期、眼睛等既有行为。

## 失败复盘与防回归

1. 基线视觉失败：数值“曲度有变化”不能证明看得出错落。修复以上几何和太阳弯曲权重；回归增加3/5/10朵真实GL早午晚与至少29局部像素的花头中心间距、35像素高度跨度约束；数值只辅助，必须看图。
2. 第一轮新专项把 JSON 浮点的往返值作严格字典相等，22项报差异。实际差异来自JSON序列化末位精度，出生/ID/时钟没有变化。改为1e-9逐字段误差检查，并保留ID/时钟精确比较。
3. 旧单株摆幅断言要求两侧超过30像素，与本次降低太阳公共弯曲相冲突。实际两侧约28–31像素且方向正确，按已查看GL结果把最低可见摆幅改为25像素；独立花盘朝向、根位与逐帧连续约束仍保留。
4. 终验中/tmp耗尽，PNG和JSON写出失败且无关香炉临时保存产生警告。该轮输出未采用。仅清理本任务中间副本和缓存后从空目录重跑；专项截图现在检查save_png返回值，隔离禁用无关香炉持久化。所有交付PNG再次打开读取并记录SHA256。
5. 为右下花留文案空隙的一次候选使两组中心间距少于29像素。未降低间距标准；调整相邻右侧两枝曲度/高度后重跑。
6. 错落拉开后真实GL暴露旧的绘制顺序：较晚ID茎横穿较早ID花盘。统一将茎叶层放到所有花盘之后，保留瓶前沿遮根；新增层级回归并再次看图。

7. 最终联图发现十朵左枝在清晨贴近屏幕边界，先前只在正午验手机尺寸会漏检。收回该枝的曲度/长度和瓶口根位，加入31个全日弧时刻的整束边界检查，要求至少4像素水平余量；实测4.69像素，旧档与新档早午晚均重新渲染。
