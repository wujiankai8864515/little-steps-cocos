# H05 收藏工程落地：复盘与边界

## 原因与修复

56193b7 中 `TravelPage._collection()` 仍是旧规整纸面：单图、名称分类、说明和普通上一件/下一件按钮。设计稿没有接入生产调用，因此从 Home 点击百宝箱无法看到新方向。

本次只替换 `_collection` 函数，分发至独立 `travel/treasure_gallery.gd`。背景重新编辑自已查看的新版参考，以原 `Art.PAPER` 资源路径导入；高清实物保留原 reward atlas。箱口实物透明轮廓直接点选，突出选中实物，木箱盖承载真实故事，箱前木牌显示收藏数/位置/点选提示；公用 HangingReturn 与实体日记入口保留。支持 0、1、4、19 件及任意有限长度：超过4件时始终显示当前物件的前一件与后一件，不设普通翻页按钮。藏品始终来自库存，没有虚构已获得物件。浏览不写库存；同数量CAS存档替换会更新视图并按UID保留选中项。

没有新增装备、付费、照片墙功能，没有修改地图、事件、日记函数、Service、Model或Store。日记仍是最后一本已收好的只读日记，未扩张成新档案管理功能。

## 发现的验证问题

首轮图形测试的日记3项失败是测试夹具传入空批注选项，模型正确拒绝归档。按实际选项ID逐条 review 后复测通过，没有修改模型以绕过校验。首轮木牌用专用毛笔字库不支持的中点显示缺字框，已移除装饰中点，最终截图无此缺字。初次日记签字偏到边缘，已按实际图调整至纸签内部。

首轮屏幕改变后的截图不是收藏画面，是前述日记夹具失败导致返回关闭。测试新增“截图时仍是收藏可见”断言；最终720×1600运行图与安全区域通过。最终 verbose GL 进程无 SCRIPT ERROR、ERROR 或泄漏退出警告。

## 工具隔离问题

对冷包脚本进行check-only时第一次独立命令漏设XDG隔离目录，官方Godot尝试写不可写的默认用户目录，报数据目录错误并退出。没有改权限或绕过限制；改用此前已建立的可写测试专属XDG目录后，相同脚本官方check-only成功。正式运行命令和README均要求设置隔离目录。该问题不涉及生产代码或游戏存档。
