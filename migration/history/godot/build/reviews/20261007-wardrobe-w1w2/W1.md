# W1 临时本地解锁候选

## 原因与范围
未接广告时，原衣柜请求只能命中 unavailable-provider 分支，不能解锁。用户最新授权在广告未接入期间点击解锁、保存结果并可穿戴，覆盖旧广告前置限制。

## 修改
- 新建明确命名的 temporary_local 策略；UI 如实说明“广告尚未接入，现在可直接解锁并保存”，按钮“直接解锁”。
- store.unlock_temporary_local 独立持久化入口，未调用 accept_verified_reward，也未构造 completed=true。
- 解锁后仍显式选择穿上；取消试穿不保存穿戴，原皮可切回，已经解锁的结果永久保留在当前本地存档。
- verified_reward 策略保留真实 provider 完成/失败分支，未知配置关闭本地授予，不把 provider 失败降级为本地解锁。
- 存档失败回滚解锁或穿戴；重新配置存档槽先清理旧状态，防槽之间泄漏。
