# 照片墙控件画风实施缺口修复

触发：独立审计对照定稿与b745实图，标题、提示、挂位标签和换批牌仍是规则几何纸底、普通细字，叶/五金/破纸纹理缺失。
确证根因：初版用自绘占位几何代替应分层制作的纸木美术，不能以功能测试通过抵消。
修复：五类真alpha图层与现有夹子/纸框共用单atlas；使用固定许可MaShanZheng逐字glyph（圈数字明确WenKai来源），实时字符串排版/计数，缺字报PHOTO_INK_GLYPH_MISSING，无系统fallback。保持公共返回/气泡原组件。标签命中覆盖铜环纸牌完整显示范围。
回归：官方导入RGBA像素exact、实际GL日夜/宽度/DPR2/拖放/切批/存档入口；全部0–30计数字形和未知字拒绝。旧两照片清晰度仍是下一独立项，不在此项宣称已过。最终合组需重新预检/远端源/正式包/Web。
