## 测试夹具失败与修正

- 首次打测试覆盖包未设置隔离 XDG 目录，Godot 报默认用户目录不可写。改为本轮本地隔离环境，正式编译日志无此错误；没有改权限或绕过限制。
- 首个测试覆盖层采用改名 raw `.gd` 加 remap，桥接脚本的常量依赖解析失败。该次运行未产生通过证据。改用官方 4.5.2 token export 的原路径 `.gdc` 与 `.gd.remap` 两个条目，依赖按正式路径解析；两次独立重建得到同一覆盖包 SHA256 `14f7f3554866fd0d0a5d91d1a99f2474534ac4a709a75278172fcadac373d66f`。这只是显式候选覆盖包，不宣称正式部署包。
- 一次早期 GL 夹具立即退出，产生 ObjectDB 清理警告。夹具改成 queue_free 后等待三帧，最终 GL 无对象泄漏警告。产品代码没有因此变更。
- 追加 headless 时，未渲染窗口的 pointer hit test 没有打开按钮，后续访问 choice_0 失败。后续 signal-only 尝试又暴露夹具过早选择：未等待公共气泡真实 reveal 完成，选择被 phase 守卫正确拒绝。现先等待实际 hold 状态，不伪造动画相位；headless 明确限定为 button signal 生命周期检查，GL 保持真实 viewport 鼠标事件。报告单列 input_mode，不把 headless 当真实输入或画面证据。最终 headless 186/186，所有失败记录保留。
