# D03 公共触摸按钮一次性与取消契约

## 触发与确证

来源是本组 D03/A034 高屏返回的真实 root 输入负测。候选基于已发布 c242，增加 B27 高屏同路径扩边；初始 index SHA256 为 `3c024525305226a30620b765c5e84d2456f5057f622ee965b22371926634a0ee`。所有运行从空 res 挂精确 PCK，使用官方 Godot 4.5.2 和原生 Mesa GL。

一个公共输入契约有两个明确子缺陷，不是七个产品缺陷：

1. 暗室返回牌触摸取消后，同位置 `DEVICE_ID_EMULATION` 鼠标按放仍进入 Home。拆分红测证明真鼠标拖出和 canceled touch 本身均不导航；模拟鼠标 up 才令 `DARKROOM → HOME_RETURNING → HOME`。公共控件 fixture 同时证明正常 touch 加模拟鼠标会重复 `pressed`/toggle。
2. touch 正常 release 已排队 deferred 激活时，外部 cancel_touch、失焦、隐藏再显示或移出树再入没有撤销这个旧回调，仍可迟到激活。

初始合测 `midstrike_v1` 有一个原始导航失败及四个级联断言失败，未把它们当成五个独立缺陷。独立 `emulation_v1` 是 13 检查、1 失败；公共控件 `button_red` 是 18 检查、7 失败。详细输入状态、日志及包 SHA 见本组 evidence。

## 根因与最小改动

原 `_input` 在 `_touch_index == -1` 后立即返回，取消后原生 Button 仍处理模拟鼠标事件。只在本控件可见、启用且命中本控件矩形时屏蔽模拟鼠标；不吞其他控件区域、不替换原生真鼠标或键盘行为。

将正常释放清理与取消分开。正常释放保留一次 deferred 激活；cancel_touch 增加代际，生命周期通知令旧回调失效。回调仍核 disabled、在树与可见状态。没有改布局、描边、资源、预算或暗室重入策略。

## 红绿与生产调用

新候选仅通过官方引擎编译公共按钮，替换 index 中一个既有 `.gdc`；无源码覆盖 res，无资源 entry 增量。index 从 2,230,308 B 到 2,230,628 B，SHA256 `7cf58fd1316a8086849dae03c1ddcce00fbfcfcc3de4f7fb34dfbc9982d06c6c`。其他包保持原 SHA。完整正式构建仍由关联组流程执行。

- 公共控件同脚本：18 检查由 7 失败到 0 失败。覆盖正常触摸、触摸+模拟鼠标一次性、取消、拖出返回、toggle、真鼠标/Space、隐藏/失焦/树移除和 deferred 撤销。外部普通 Button 的模拟鼠标仍正常，证明没有全局吞鼠标。
- 暗室实际返回牌：独立同脚本 13 检查由 1 失败到 0 失败，取消后留在暗室的真实 PNG 已看。
- Home 公共确认与返回实际调用：13/13；挥击未接触即退出再入：31/31；修后 D05 延迟/失败/取消/暖复用：25/25。以上新代码相关合计100断言0失败，原生执行无SCRIPT ERROR/ERROR。
- 新runner记录所有子进程已退出，继承测试脚本hash未变化。

## 仍未验证

这不是浏览器触摸或硬件触感证据。空 res 的实际 App 为隔离暗室省略开场格漫，不能称冷网站全流程。Audio Dummy 不证明听音。该公共脚本也被 DoorHotspot、Comic、Loading、Travel、收藏和设置复用，父集成将用合组正式包补现有登录 28 项；不把控件矩阵等同全页面回归。

## 测试执行事件

第一次独立 check-only 没有隔离 XDG 目录，Godot 无法写缓存目录并崩溃；隔离为 QA 自有 data/config/cache 后解析通过。此为 QA 启动配置错误，未改产品。正式 QA runner 始终隔离 XDG，且新封装记录所有子进程 PID/退出值与继承脚本 hash。首轮视觉期间有父方短暂 headless 准入 CPU 负载，未用此轮证明 60fps 或真实动画墙钟性能。
