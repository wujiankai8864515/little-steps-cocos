# R9 发布后的五项新视觉反馈

本清单仅用于 R9 发布后用户确认推进的五项新反馈，不重开或混入已交付的旧七项。来源基线：生产 `5c37fb30fe088e998c414ed32a3e26fb551c2689`，私有文档基线 `b59373583ef615d28fd6137227fba9d6a82d9de2`。用户要求每项源码及时独立备份，关联组验收后统一正式构建和部署。

1. N1 格漫加载提示与已有“点击进入”共用同一位置。实际字形、三点动画、五种布局、等待重复点击、取消/失败/重试和真实 Home 准备门禁需要分别核验。
2. N2 奇遇做出选择后的结果文字恢复纸质底板。复用既有手绘票纸；十条当前文案、回看、取消、AI、重复输入、横竖/小屏和收纳一次性保持。
3. N3 出发前背包主角原地渐隐，无向上或侧向位移。保留原始素材、脚锚、缩放、4.8 秒序列、一次云、重复确认/取消/迟到/失败后重试与存档不重播。
4. N4 照片墙出现肉眼可见的宽软斜向光束及受光层次，昼夜连续，与已认可衣柜的柔和光照质量相符。不得增加窗口，不改获认可衣柜。照片纸、夹子、藤叶、主角、投影、保存/取消/重开与已获得照片不退化。
5. N5 旅行页同样具备宽软光束、场景受光和昼夜变化。共用纯光场算法，各页只配置差异；不得复制整套页面光影系统、增加原图或破坏地图、标牌、钟/落叶、路线、一次结算和四尖星光。

## 分层状态与来源

每项的独立中文修复提交及原 worker 到私有主线的映射记在 `requirements.json`。候选组件、显式单脚本覆盖、真实正式分包、Web 初始化和用户视觉认可均是不同层次。候选通过只允许对应候选声明；尚未运行的阶段必须保持待验。

## 正式关联组放行门槛

- 完成一项立即普通追加私有 GitHub，不 squash，不 force。读回完整 commit/tree、blob/mode、所有变更文件字节；保留旧 milestone。同步独立 Library 固定版本与恢复验证。
- 所有生产源与资源分组稳定后，字体完整性与资源合同预检；提交最终元数据并再次远端读回，再从同一干净 commit 一次构建官方 Godot 4.5.2 native 和 non-thread Web。
- 空 res、隔离 HOME/XDG、精确十一份 PCK、全部候选覆盖显式 none；递归 `qa_source_guard` 与实际命令、fixture/pack SHA 一起存档。不能用物理完整工程或候选包替代正式包。
- 逐项重新执行可见效果与交互检查，实际查看昼夜/尺寸/输入截图；额外重跑 R9 的相关照片、衣柜、旅行、出发、暗室与收藏/日记回归。
- 光照开关实际像素贡献、04:00/20:00/24:00 连续性、Shader/纹理/节点缓存重开稳定性须有证据。绘制次数减少不能单独证明帧耗时改善。
- 同一云机、同一夹具、分离无争用的 R9/新正式包性能与生命周期比较。128 entries/256 MiB 门禁不变；节点/对象/RSS 完整记录并调查无法解释的增长，不以固定自然花朵/字体缓存额度掩盖新问题，不清生产缓存或冻结正式性能运行来制造通过。
- 发布前冻结源码、输入 SHA、官方工具链 SHA、native/Web 原文件与 PCK 清单。既有公开站点部署后读回34个文件与32条宿主预加载清单、11个物理 PCK；记录真实浏览器初始化边界，不声称受限浏览器已跑通 WebGL2 游戏或手机触控。
